# 方案二：腾讯云 CDN — 对用户开放 443，回源沿用机房的 8443

## 必读：哪些能「替你完成」，哪些不能

| 事项 | 说明 |
|------|------|
| **不能**由本仓库或远端 SSH 替你完成 | 开通 CDN、填加速域名与源站、`www`/`@` **CNAME** 到你账户里的解析、在 CDN 控制台 **上传 HTTPS 证书**、改 **DNS 控制台**。**这些必须使用你的腾讯云与域名控制台账号**。 |
| **已经**在机房帮你准备好的 | **Nginx 同时监听 `443` 与 `8443`**，且你已验证 **`https://www.dianfanbao.net:8443`** 可用；HTTPS 使用的证书与套件与 443 **相同**。CDN 只要把回源端口指到 **`8443`** 即可，**无需再在服务器上加一套反代**。 |

以下为 **你在浏览器里要完成的手动顺序**（产品界面可能更名，请以控制台为准）。

---

## 事前确认

1. **CVM 安全组**：放行 **TCP 8443**，来源至少包含 **CDN 全国回源**（可先 `0.0.0.0/0`，上线后再按需收紧）。
2. **证书**：准备与 `www.dianfanbao.net`（及若需要 apex）匹配的 PEM；可与现 Nginx 使用同一张 **TrustAsia** 证书，或改用 **腾讯云 SSL 证书托管**后在 CDN 里选用。
3. **站点特性**：本项目除静态页外还有 **`/__fmz_*` 动态回源**，CDN **不能**对这些路径做强缓存。

---

## 步骤 A：控制台开通 CDN、添加加速域名

1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/) → **内容分发网络（CDN）**。
2. **域名管理** → **新增域名**。
3. **加速域名**建议先加：
   - `www.dianfanbao.net`
4. **源站类型**：选 **IP**（或等价「自有源」）。
5. **源站地址**（关键）：填写 **`118.195.150.4:8443`**
   - 官方说明：可在 IP 后直接带端口；**HTTPS 回源**时请与下方「回源协议」一致。参考：[源站配置](https://cloud.tencent.com/document/product/228/41334)、[HTTPS 配置](https://cloud.tencent.com/document/product/228/41685)。
6. **回源协议**：选 **HTTPS**（与你的 Nginx **8443** 上跑的 TLS 一致）。
7. **业务类型**：选 **动静加速**或 **网页 / 小型文件** 等最接近「前端静态 + API 反向代理」的一类；若控制台有「全站 / 动静分离」更贴近 **`/__fmz_*`** 动态路径，可选此类（以当前产品矩阵为准）。
8. 提交后记录控制台为该加速域名分配的 **CNAME**，形如 `xxxx.dnspod.com`（以实际为准）。

---

## 步骤 B：HTTPS（边缘证书，用户看到的是标准 443）

1. CDN 控制台该加速域名 → **HTTPS 配置**。
2. 开启 **HTTPS 访问**。
3. **托管证书**：上传或选用与 **`www.dianfanbao.net`** 匹配的证书链（可把现 Nginx 的 `*_bundle.crt` 与 `.key` 合成 PEM，或直接使用腾讯云申请的证书）。
4. 可选：**HTTP → HTTPS** 跳转，按需打开。

用户使用 **`https://www.dianfanbao.net`** 时，看到的是 **CDN 边缘** 443 上的证书，**不再直连**你机器的 443。

---

## 步骤 C：缓存与安全 — 必须为 `/__` 放行「始终回源」

默认静态 CDN 可能误缓存 **`/__fmz_defense/`、`/__fmz_reactions/`、`/__fmz_audio/`** 等，导致功能异常。**必须**配置为不缓存或少缓存：

1. CDN → 该域名 **缓存配置**（或「节点缓存规则」「缓存键」）。
2. 新增规则（**优先级调高**，先于泛泛的 `*` 规则）：
   - **匹配**：路径前缀 **`/__`**（或分别写 `/__fmz_`）。
   - **缓存策略**：**不缓存 / TTL=0**，或等价「**绕过缓存 / 缓存关闭**」，保证 **每条请求回源到你的 8443**。
3. **`index.html`/`*.html`**：建议 **TTL 较短**（如 60～300 秒），或发布后接受「purge 缓存」习惯，便于发版后立即生效。（带 hash 的 `assets` 可走较长缓存；以你们实际构建产物为准。）
4. 官方「高级回源」与按路径区分源站可参考：[高级回源配置](https://cloud.tencent.com/document/product/228/39745)。

---

## 步骤 D：DNS — 让用户访问 CDN，而不是直连 CVM IP

1. 到你的 **域名 DNS**（可能是 DNSPod / 腾讯云 / 其它注册商）。
2. 将 **`www.dianfanbao.net`** 的解析改为 **CNAME**，指向 CDN 分配的 **CNAME**（不要使用 A 指向 `118.195.150.4`，否则仍会直连源站）。
3. **根域 `dianfanbao.net`（apex）**：  
   - 若也需 `https://dianfanbao.net`：**在 CDN 再添加一条加速域名** `dianfanbao.net`，回源与同端口同上；apex 无法用纯 CNAME 时，可用注册商提供的 **CNAME 扁平化**，或仅用 **/www** 作主站、根域 **301 → www**。按你现有域名策略选一种。
4. 等待 TTL 生效（几分钟到数十分钟）。

生效后：**全国用户走 CDN 443** → **CDN HTTPS 回源 `118.195.150.4:8443`**。

---

## 步骤 E（可选）：源站仅对 CDN / 可信网段开放 8443

回源 IP 段由腾讯云维护、会变动，请以最新文档为准，例如：**获取中间源 / 回源 IP**（在控制台帮助或站内搜索「CDN 回源 IP」）。

收紧安全组能减少「绕过 CDN 直连源站」，但运维成本更高：规则需随官方列表更新。

---

## 备选：边缘安全加速平台 EdgeOne

若你已使用或被引导使用 **EdgeOne**，思路相同：**业务域名**、`www`，**源站协议 HTTPS**、地址 **`118.195.150.4:8443`**，边缘 HTTPS 与用户侧 443。「不缓存 **`/__*`**」同样在 EO 控制台做 **缓存 / 规则引擎**排除。控制台入口：`边缘安全加速` / `EdgeOne`（以当前产品名为准）。

---

## 自检清单

- [ ] 浏览器 **`https://www.dianfanbao.net`**（无端口）能打开；
- [ ] CDN 控制台 **「回源成功」命中率**、无大量 502/522；
- [ ] 站内涉及 **`/__fmz_*`** 的 Tab（防御塔、赞踩、音频等）功能正常；
- [ ] （可选）源站 **`443`** 仅内网或未使用，减少对「直连源站有问题」场景的依赖。

若在某一屏（例如 **源站带端口是否接受**）因产品版本被拒绝，可把 **报错截图文案**记下来，再问客服或查阅当前地域的 CDN 是否在「HTTPS 高级回源」里单独绑定端口。
